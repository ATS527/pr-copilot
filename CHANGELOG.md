# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project follows Semantic Versioning.

## 0.0.1 - 2026-05-01

- Added pull request and merge request review workflows for GitHub and GitLab.
- Added local checkout and restore flows for reviewing changes in VS Code.
- Added AI Insights with opt-in enablement, provider selection, model selection, and configurable insight modes.
- Defaulted AI Insights to off for faster startup and review open flow.
- Simplified AI insight generation to Summary and Bugs and Problems only.
- Added provider-aware SCM token setup in the UI for both GitHub and GitLab.
- Prepared the extension for marketplace packaging with a PNG extension icon.
